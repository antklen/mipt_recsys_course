# Итоговый проект

Два варианта на выбор

1) Провести исследование какой-то темы, сравнить и разобрать несколько подходов.
2) Реализовать какую-то статью и предложить ее улучшения и доработки.

Можно выбрать тему или статью из заданного списка либо предложить свою тему или статью, но ее необходимо согласовать.

### Темы для исследования

- Исследование способов борьбы с проблемой item cold start в sequential recommendations / в классических рекомендациях.
- Исследование способов борьбы с popularity bias в sequential recommendations / в классических рекомендациях.
- Исследование разных способов повышения разнообразия выдачи в рекомендациях.
- Исследование качества и эффективности Approximate Nearest Neighbor Search в neural retrieval.
- Исследование разных способов negative sampling и/или функций потерь в sequential recommendations.
- Исследование разных training objectives помимо next-item prediction в sequential recommendations.
- Исследование разных способов построения semantic ids на основе контентной информации для генеративных рекомендаций.
- Исследование разных способов учета коллаборативной информации при построении semantic ids для генеративных рекомендаций.

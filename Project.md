# Итоговый проект

Два варианта на выбор

1) Провести исследование какой-то темы, сравнить и разобрать несколько подходов.
2) Реализовать какую-то статью и предложить ее улучшения и доработки.

Можно выбрать тему или статью из заданного списка либо предложить свою тему или статью, но ее необходимо согласовать.

Для первого варианта нужно провести анализ литературы по теме, проанализировать несколько статей, выбрать 2-3 подхода для реализации (не обязательно из статей, можно из других источников / свои), выбрать подходящий датасет, определиться с сетапом экспериментов и простыми бейзлайнами, оценить и сравнить предложенные подходы.

Для второго варианта нужно выбрать статью, проанализировать какие у нее достоинства и недостатки, проанализировать похожие статьи на эту же тему если они есть, попробовать воспроизвести статью на одном из датасетов, которые использовались в статье, предложить 2-3 гипотезы (это могут быть свои идеи, могут быть из каких-то источников) по улучшению / развитию идей / устранению недостатков и протестировать их на данных.

### Темы для исследования

- Исследование способов борьбы с проблемой item cold start в sequential recommendations / в классических рекомендациях.
- Исследование способов борьбы с popularity bias в sequential recommendations / в классических рекомендациях.
- Исследование разных способов повышения разнообразия выдачи в рекомендациях.
- Исследование качества и эффективности Approximate Nearest Neighbor Search в neural retrieval.
- Исследование разных способов negative sampling и/или функций потерь в sequential recommendations.
- Исследование разных training objectives помимо next-item prediction в sequential recommendations.
- Исследование разных способов построения semantic ids на основе контентной информации для генеративных рекомендаций.
- Исследование разных способов учета коллаборативной информации при построении semantic ids для генеративных рекомендаций.

### Какие требуются артефакты проекта

- Репозиторий с работающим кодом
- Pdf отчет
- Презентация на занятии 9 декабря

### Критерии оценки

- **Воспроизводимость:** код запускается и соответствует тем результатам, которые предоставлены в отчете; есть инструкция для запуска.
- **Experimental setup:** разумный выбор датасета, подготовки и разбиения данных, бейзлайнов, сетапа для оценки качества.
-  **Research quality:** адекватные гипотезы для проверки, правильно выбранные эксперименты для их подтверждения, анализ результатов.
- **Презентация результатов:** качество отчета, репозитория с кодом и презентации.

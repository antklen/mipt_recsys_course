# MIPT RecSys Course

Материалы курса "Рекомендательные системы" кафедры математики искусственного интеллекта (МФТИ).

### Syllabus

1. Введение: постановка задачи, данные и особенности.
2. Методы оценки рекомендательных систем. Простые бейзлайны.
3. Матричная факторизация: SVD, ALS, iALS, BPR-MF. Линейные item-item модели: SLIM и EASE.
4. Нелинейные автоэнкодеры и гибридные подходы.
5. Two-stage approach.
6. Neural retrieval. Two-tower models.
7. Neural ranking.
8. Sequential recommendations.
